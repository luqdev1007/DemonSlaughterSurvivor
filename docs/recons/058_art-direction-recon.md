## 0. Что всплыло до основной части (читать первым)

1. **`M.E. Castle Creator` — копия с варез-сайта, не с Asset Store.** `Assets/M.E. Castle Creator/Demo_Scenes/README.txt` начинается с «This asset was shared by https://unityassetcollection.com … Telegram: @assetcollection». Этот сайт сам пишет, что раздаёт файлы «только для изучения, не для коммерции». Для релиза в Steam такой пак использовать нельзя, пока его не купят (официальная страница — Asset Store 55455, около $35). Остальные паки этой метки не несут (поиск по `*.txt/*.rtf/*.md/*.cs` по всему `Assets/`). Лицензию по `.meta` не проверить: Asset Store не пишет её в файлы пака. Поэтому «чистые» значит только «нет признаков перепаковки», а не «лицензия подтверждена».
2. **Почти всё окружение — на шейдерах Built-in, в URP оно розовое.** Проект на URP (`PC_RPAsset`). Префабы `Castle_Set_2.0`, `Polylised`, `StoneKeep`, `Mountain Terrain`, `Medieval Bridge`, `Old Sea Port`, `Fantasy Forest` ссылаются на `.mat` с `Standard` / `Standard (Specular setup)` / `Legacy Shaders/*`. В превью `AssetPreview` все 18 проверенных пропсов вышли сплошным magenta. Встроенные в FBX материалы уже на `URP/Lit`, но префабы на них не ссылаются. Перед использованием нужен Render Pipeline Converter или ручная перепривязка материалов. Это отдельная задача с изменением ассетов, в этот заход не входила.
3. **`Polylised` экспортирован с осью Z вверх** (3ds Max). Высота у всех префабов лежит по Z: фонтан `4.6 × 4.6 × 2.3`, башня `11.4 × 11.4 × 26.1`, в превью башня лежит на боку. При расстановке нужен поворот −90° по X или переимпорт с `Bake Axis Conversion`.
4. **Шрифты UI-кита без кириллицы, и пересобрать их нельзя.** 13 TMP-ассетов `GUI Pro-FantasyRPG` (Alata, Josefin Sans, Play) — статические атласы на 97–230 символов, ни одного символа из U+0410–U+044F, `sourceFontFile = null` (TTF в паке нет). Русский интерфейс на них не соберётся. Исходники шрифтов брать с Google Fonts (лицензия OFL, тексты лежат в паке). Поддерживают ли эти три гарнитуры кириллицу — **не проверено**, смотреть на странице шрифта. Тема рядом с уже записанным техдолгом «Динамический атлас `LiberationSans SDF - Fallback.asset`» (CLAUDE.md §8).
5. **Ни один новый пак окружения или UI пока не используется.** `GetDependencies` по трём сценам Build Settings и по всем сценам, префабам и SO в `_Project` даёт только `SimpleAssets` (дьявол), `Troll`, `Vefects` (кровь), `TextMesh Pro`, `Settings`. `MainMenu.unity` зависит только от TMP.
6. **Разрушаемые пропсы вне MVP.** В `GDD.md` §11 их нет ни в MVP, ни в «заложено архитектурно». Часть 1 и часть 2 про разрушаемость — справка на будущее. Если пойдёт в работу — это расширение скоупа (CLAUDE.md §6 п. 6), плюс чеклист производительности `ARCHITECTURE.md` §13.1 (пул, без `MaterialPropertyBlock`, предохранитель числа живых).
7. **Расхождение с `LORE.md` §4:** акт 1 — «дикие звери, выживание». Сцена уровня 1 в задаче — «замковый двор». Друг другу они не противоречат (место действия акта 1 нигде не задано), но стоит держать в голове при выборе настроения.
8. **Паки добавлялись во время разведки.** Пока шла сессия, пришли коммиты `87f561ca` … `896da560` (Medieval Bridge, MedievalCastlePackLite, Fantasy Forest, terrain layers, Old Sea Port, 3DForge). Они включены в инвентаризацию. Всё, что придёт после `896da560`, сюда не попало.

### 1.2 UI-киты подробно

**`GUI Pro-FantasyRPG` (Layer Lab)** — основной по объёму.
- **Стиль:** flat casual, мобильный. Скруглённые выпуклые кнопки, ленты-флажки, пузыри, насыщенные синий / мятный / фиолетовый / зелёный. Видно на контакт-листе (кнопки, `Title_Ribbon_*`, `Label_Bubble`). К «тёмному фэнтези между DMC и Diablo» не близок; ближе к мобильным RPG.
- **Перекраска — хорошая.** Кит послойный: у каждой детали есть варианты `*_White_Bg`, `*_White_Border`, `*_InnerDeco`, `*_Glow`. В выборке по компонентам серых спрайтов: Frame 104 из 153, Slider 46 из 73, UI_Etc 24 из 38, Popup 9 из 12, Button 14 из 36, Label-Title 19 из 71 (серый = средняя насыщенность < 0.08). Белые слои красятся через `Image.color` без новых текстур. Цветные варианты запечены.
- **Шрифты:** Alata (обычный + 9 атласов с обводкой 28–210), Josefin Sans Bold, Play (`PlayGold`, `PlayCombo` — по 11 глифов, то есть цифры). Кириллицы нет — §0 п. 4.
- **Иконки:** 361 пиктограмма (белые, красятся), 90 предметов, 45 экипировки — в 6 размерах. Пиктограммы нейтральны по стилю, предметы — casual.
- **Фоны** `Demo_Background` — расписные сценки (пещера, свет, лава), casual-тон. Как фон меню не годятся по стилю; годятся как пример того, как кит раскладывает слои фона.
- Анимации — 13 клипов, `UIParticle` в `Extensions`.

**`GUI_Parts`** — ближе всех к задаче.
- **Стиль:** тёмный нейтральный — тёмно-коричневые/чёрные панели, тонкие бронзовые рамки, круглая рамка с медным ободом, `button_cancel` в тёмно-красном. Орнамента почти нет, то есть «сдержанные рамки» из брифа.
- **Перекраска — плохая:** 0 из 44 серых, всё запечено в цвет. Менять тон — только через `Image.color` поверх (затемнение работает, смена оттенка — нет) или перерисовка.
- **Иконки навыков** (`skill_icon_01…04`, с фоном и без) — расписные, с огнём и свечением (рука с пламенем, череп в фиолетовом, молот в золоте). Тон ближе всего к Diablo III. Есть `Hp_frame` / `Hp_line`, `bar_ready`, `name_bar` — заготовки HUD.
- Шрифтов нет.

**`Freeui/ZOSMA`** — мобильный, «бумажный»: бежевая плашка, свёрнутая бумага, светлые шестерёнки. Перекраска плохая (11 из 70 серых). По стилю мимо брифа.

**`RGP icons free start pack`** — casual расписные предметы (зелья, рыба, гриб, меч, щит) плюс `bg_black_frame`. По стилю мимо тёмного фэнтези, разве что как временная заглушка.

**`Blink/Art/Icons/Classes`** (Assassin, Elementalist, HolyDarkness, Symbiose, Warrior) — иконки способностей по классам. Детально не открывались. Кандидат под иконки способностей берсерка, нужен отдельный взгляд глазами.

### 1.4 Разрушаемость: что физически годится «разлететься на куски»

Общее: **ни в одном паке нет заранее нарезанных осколков.** Все бочки и ящики — один меш (`parts = 1`), `Rigidbody` нет ни у одного префаба. Значит, любой вариант «на куски» требует либо нарезать осколки (Blender Cell Fracture или аналог), либо заменить разлёт частицами-обломками (сэмплы `Old Sea Port/EffectExamples` — `Wood`, `Stone`, `Metal` — это эффекты попадания по материалу), либо делать рантайм-фрактуру сторонним пакетом. Это развилка на потом, не сейчас.
