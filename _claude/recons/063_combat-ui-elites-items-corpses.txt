2. КАРТА БЛОКОВ (путь данных)
======================================================================
Казнь по элитке:  EnemyConfig._isElite → EnemyFactory (тег Elite) → StartExecutionSystem (босс, затем Elite) →
                  AdvanceExecutionSystem (формула HitDamage для всех целей).
Резкий взмах:     FaceAimSystem (PredictiveLead/Swing) → StartSwingSystem.TryPredict (sharp) → Swing.DamageScale/PushTicks/
                  IsSharp → AdvanceSwingSystem (урон, PushFromPoint) → PlaySwingFeedbackSystem → ISwingStyleView → SwordTrail.
Дальность взмаха: WeaponConfig._reach → EquipStartingWeaponSystem (SwingReach) → RecomputeStatsSystem → StartSwingSystem
                  (покрытие / reach) → AdvanceSwingSystem (SwingSweep.Hits(reach), _arcBonusDegrees).
Доворот:          StartSwingSystem (Swing.Target) → AssistSwingFacingSystem (после FaceAimSystem).
Таран / вихрь:    AdvanceEnemyChargeSystem (LockedDirection, HomingBias) → ApplyEnemyChargeVelocitySystem (Home);
                  AdvanceEnemySpinSystem (DashDelayTicks) → SteerEnemySpinSystem (после ApplyMoveSpeedSystem).
Окно перков:      OfferUpgradesSystem → IUpgradeChoiceSink → UpgradeChoice → HudPresenter.RefreshChoice/Describe →
                  UpgradeChoiceView (N карточек) → PerkCardView + PerkTooltipView. Вёрстка: Editor/HudUiBuilder.cs.
Панель способн.:  PublishAbilityPanelSystem (группа 12; рывок + взятые перки по типу поведения) → IAbilityPanelSink →
                  AbilityPanel → HudPresenter.RefreshAbilityPanel → AbilityPanelView/AbilitySlotView.
Цифры / DPS:      PublishDamageDealtSystem (группа 12, Inc<DamageEvent, DamageApplied>, только Enemy) →
                  IDamageNumberSink → DamageNumbers (UI) → DamageNumberLayerView;  IDamageDealtSink → DpsMeter → DpsView.
                  Клавиша ~ → DpsToggleInput → HudPresenter → GameSettings.DpsVisible.
Настройки:        GameSettings (Services, persistentDataPath/settings.json, Version 1) : ISoundSettings, ICombatTextSettings →
                  SettingsPopupPresenter (меню и пауза).
Вихрь клинков:    TriggerCounterStrikeSystem (группа 6, сразу после TickWeaponCooldownSystem; кулдаун + IsSurrounded) →
                  CounterStrikeArmed → StartCounterStrikeSystem.
Элитки:           WaveTimelineConfig._eliteChance/_eliteAffixes → SpawnWaveSystem.ResolveAffix (поток enemy.elite) →
                  EnemyFactory.ApplyAffix (Elite, EliteAffix, модификаторы «enemy.elite», BodyRadius × scale) → IEliteView.SetElite.
                  Пределы: WaveTimelineValidator.ResolveMaxMoveSpeed × MaxEliteSpeedFactor, ResolveMaxBodyRadius × MaxEliteScale.
Предметы:         QueueItemDropsSystem (после DropGemsSystem, Inc<Enemy, Elite, DiedEvent>) → PendingItemDrops →
                  OfferItemsSystem (после OfferUpgradesSystem; ждёт закрытия окна перков; ItemRoller, поток stream.item-offers) →
                  UpgradeChoiceGate.Await + IItemChoiceSink → ItemChoice (UI) → UpgradeChoiceView «ItemChoice» →
                  ввод 1–4 → ApplyItemChoiceSystem (системы выбора) → EquippedItem + модификаторы «item.<slot>».
Перезарядка:      StatId.AbilityCooldown → AbilityCooldownScale (герой) → AbilityCooldowns.Scale в AdvanceDashSystem,
                  StartDashFinisherSystem, StartHeroicLeapSystem, TriggerCounterStrikeSystem, StartExecutionSystem.
Трупы:            ReapDeadEnemies → IViewFactory.Retire → ViewPool (срок 10–15 с, аниматор выкл. после клипа смерти,
                  погружение, лимит 60, за кадром — сразу) → ViewInterpolator.BeginRetire/AdvanceCorpse.

3. РЕШЕНИЯ И РАЗВИЛКИ
======================================================================
- Предметы — только внутри забега (решение разработчика); GDD §8/§11 поправлены. Мета-версия — позже.
- Слоты: оружие, броня, кольцо, сапоги, амулет. Запоминание грейда снятого — не делается. Лут — в WaveTimelineConfig
  (одна таблица на таймлайн, не на волну).
- Окно предметов — сразу при убийстве элитки, как лвл-ап; очередь с окном перков.
- Тролль — элитка + случайный аффикс. DPS — окно 15 с в префабе (DpsView._windowSeconds).
- Ранг перка = уровень, редкость перка — только визуал (В4 не отвечен, взята рекомендация). Крит — только стиль цифр (В6).
- Трупы: вариант А (без регдолла), затем — трупы не пинаются вовсе, пинаются только куски.
- Цвета UI: перевод в линейные только новых элементов; флаг Canvas.vertexColorAlwaysGammaSpace не трогали, чтобы не
  сдвинуть принятые цвета HUD (отвергнуто: глобальный флаг).
- Окно предметов переиспользует карточку перка (ранг — точки, редкость — рамка, тултип с RankLabel) вместо отдельной вьюхи.
