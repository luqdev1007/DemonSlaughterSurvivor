Как считается. Осколки воспоминаний = эффективный урон (без оверкилла, обрезан по остатку HP цели) × коэффициент уровня из конфига + фикс за босса. Магические осколки = сумма по найденным предметам с весом редкости. Обе награды выдаются и при смерти. Реликвия падает только за первую победу над боссом; при повторной победе ничего связанного с ней не даём. Статистика забега без подсветки, отдельной кнопкой.
Оружие — единственный мета-слот героя. В нём гнёзда: самоцветы по цвету гнезда (призматическое принимает любой) и одно гнездо реликвии. Уровень оружия качается за магические осколки и открывает гнёзда и свойства. Свойства каждого оружия свои: «Жажда стали» у клинка и «Цепь казни» у топора — это твои идеи из реликвии, переехавшие в само оружие. Кликни по гнезду.

Охотник на демонов

Свойство класса (ранги) Модификатор перка из забега Ключевой выбор (одно из двух) Золотой узел
Структура в духе артефакта Легиона. Три ветки по осям героя: ярость, клинок, демоническая рука. Модификаторы меняют конкретные перки забега, поэтому каждый новый перк автоматически даёт пару узлов. Ключевой узел заставляет выбрать стиль. Золотой узел требует дойти до конца двух веток из трёх.
