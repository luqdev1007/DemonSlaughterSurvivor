3. Карта блоков: путь данных
==========================================================================
Герой из данных: MainMenuView → MenuHeroLineup (All<CharacterConfig>, клик) → IHeroSelection
  (settings.json) → RunRequest.CharacterId → SpawnPlayerSystem: базовые статы + компоненты только
  заданных модулей (DashStats, UltimateCharge+RageState, TorsoAim, BackleapStats, Height) →
  EquipStartingWeaponSystem (меч) / EquipBowSystem (лук). Перки: OfferUpgradesSystem →
  PerkPool.ForCharacter(RunContext.CharacterId).
Прицел: InputService → ReadInputStateSystem (InputState: курсор, ПКМ) → AimTorsoSystem (TorsoAim:
  цель/направление корпуса) → FaceLegsSystem (Facing ног, Backpedal, TurnSide) →
  SyncAimViewSystem → IAimView → AimRig (MoveX/MoveZ/Turn в аниматор, скручивание позвоночника).
Выстрел: TickWeaponCooldownSystem → StartBowDrawSystem (BowDraw, PowerShotCooldown, «Draw») →
  ReleaseBowShotSystem.Volley (мультивыстрел, мощная стрела, комбо; Projectile + Arrow + View) →
  MoveSystem → AdvanceArrowsSystem (индекс → попадание/пробитие → DamageEvent вида Weapon с
  CritChanceBonus; взрыв → AreaStrike + LeapImpactFx; IArrowView.MarkPierced) →
  ResolveAreaStrikeSystem → ResolveHitOutcomeSystem (метка: урон и шанс крита; крит) →
  ApplyDamageSystem.
Backleap: InputService (Space/СКМ, удержание) → ReadBackleapInputSystem (BackleapRequest, Held) →
  StartBackleapSystem (Leap от цели / Hop; неуязвимость) → MarkOnBackleapSystem (HunterMark, MarkFx) →
  AdvanceBackleapSystem (Velocity, Height, фазы, пике → AreaStrike, кулдаун) → UpdateAirborneSystem
  (Airborne) → атаки по герою с Exc<Airborne> → SyncAirViewSystem → IAirView (AirPhase, крылья
  WingsFx, звук Backleap) и SyncLeapLiftViewSystem → SetLift.
Метки: TickHunterMarksSystem (срок, MarkFx следует за целью, уборка).

4. Развилки
==========================================================================
Решены разработчиком:
  - Пустой/малый пул перков — пропуск окна + окно на 1–2 карточки.
  - Лук — в левой руке (по клипам Mixamo), импорт glb — временный glTFast.
  - Крылья — модель разработчика; звуки — файлы разработчика.
  - Комбо «Пронзающий веер» — отдельный перк; без него мощная только центральная стрела.
Решены по умолчанию (отмечены в журнале):
  - ID character.huntress (конвенция character.berserk), не hero.archer из промпта.
  - Риг Generic (как у всех героев), не Humanoid из промпта.
  - Huntress 5 м/с (берсерк 6) — бег не проигрывается быстрее ×1.5.
  - Мощный выстрел — по кулдауну (6/5/4 с), а не «каждый N-й»; с мультивыстрелом без комбо —
    центральная стрела (при чётном числе — левая от центра).
  - Анимация крыльев процедурная (у модели нет клипов), позы в осях тела.
  - Клики по героям в меню — проекция границ модели на экран, без физики.
  - Бонус крита — поле DamageEvent, метка охотника — в ResolveHitOutcomeSystem (единая точка).
Отвергнуто:
  - Отдельный TransientFx-компонент для взрыва — переиспользован LeapImpactFx (уже общий).
  - Обобщённый AbilityDefinition — по-прежнему ждёт артефакта (ARCHITECTURE §7).

6. Сценарий ручной проверки (несданное)
==========================================================================
Удобно на Shift+2…3 (замедление).
1. Крылья: отскок в беге — замах, взмах перед собой, раскрытие; удержание — парение, взмахи, рябь
   кончиков; подскок стоя — взмах вниз; пике — сложены; приземление — исчезают.
2. Звуки: выстрел на каждой стреле; Backleap — выше обычного.
3. Мощный выстрел: длинное натяжение, раскалённая широкая стрела пробивает толпу, красный трейл с
   первого врага, чаще криты, кулдаун на панели 6/5/4 с.
4. Мультивыстрел: 2/3/4 стрелы веером; с мощным — пробивает центральная.
5. «Пронзающий веер»: в окне только при обоих родителях; после взятия весь веер мощный.
6. Взрывная стрела: иногда огненный взрыв в месте попадания, соседей бьёт и отбрасывает.
7. Метка охотника: Backleap у толпы — руна и кольцо на ближайших, по ним выше урон и чаще криты,
   гаснет через 4–6 с или со смертью.

==========================================================================
7. Незакрытое, риски
==========================================================================
- Лицензия DemonWings не указана (CLAUDE §8).
- Отладочный Shift+1…0 (CLAUDE §8): Shift+1…3 в окне перков ещё и выбирают карточку.
- 4 запечённых клипа берсерка расходятся с исходниками (CLAUDE §8) — не трогалось.
- Ручные шаги Huntress: Game/Bake Huntress Clips, Game/Build Huntress Animator — теста свежести нет.
- Клипы сальто/прыжка поднимают таз поверх SetLift — визуальная высота больше симуляционной.
- Взрыв стрелы разрешается тиком позже попадания (ResolveAreaStrikeSystem раньше полёта стрел).
- Arrow.Hits растёт удвоением массива при пробитии >16 врагов (редкая аллокация на сущность).
- Иконки всех пяти перков и Backleap — временные.
- Тетива не тянется за рукой; клипы AimWalk_* и Run_Stop запечены, но не используются.
- Метка и взрыв — без стресс-замера на level.stress (CLAUDE §6 п. 9): эффекты пулятся, без теней,
  без MaterialPropertyBlock, но замер не делался.
