======================================================================
0. ГРАНИЦА MVP — ФЛАГ ДО НАЧАЛА (CLAUDE.md §6 п.6)
======================================================================
- Предметы, слоты, инвентарь — в GDD §11 явно «заложено, но не в MVP»; GDD §8 описывает их как МЕТУ:
  4 слота (броня, оружие, кольцо, артефакт), падают с мини-боссов, прокачиваются.
  Запрос — другое: предметы ВНУТРИ забега, с элиток, карточками. Это меняет GDD, а не реализует его.
- Элитки — шаг 10 роадмапа («враги, элитки»), то есть в MVP, но раньше очереди.
- UI перков, цифры урона, DPS — в рамках шага 7 (прогрессия забега) и полишинга, MVP не расширяют.
Решение за разработчиком (В1).

======================================================================
1. ЧТО ЕСТЬ В КОДЕ
======================================================================
- Окно перков: UI/UpgradeChoiceView.cs — 3 кнопки, у каждой только title + description (TMP).
  Текст собирает HudPresenter.RefreshChoice: "[N] Имя", "описание\nуровень / макс".
  Данные: UpgradeOffer(PerkId, NextLevel) из OfferUpgradesSystem через IUpgradeChoiceSink → UpgradeChoice (R3).
- PerkConfig: _displayName, _description, _levels (модификаторы StatModifierEntry), _behaviour, _requires.
  Иконки, редкости, ранга НЕТ.
- Урон: DamageEvent {Target, Source, Amount, Kind, IsSlash, SourcePerk}. Крита и стихии НЕТ нигде.
- Настройки: SoundSettings — только в памяти, не сохраняются. Ответ В3 разведки 060 (JSON с версией в
  persistentDataPath) не реализован — блок 1C не делался.
- Статы (Core/StatId.cs): MoveSpeed, MaxHealth, DashCooldown, WeaponDamage, WeaponCooldown, AttackSpeed,
  DamageTaken, PickupRadius, LifeOnKill, LifeOnHit. Крита нет, общего «кд способностей» нет.
- Тег Elite есть (2026-10-17): EnemyConfig._isElite, у тролля включён; казнь бьёт Elite.
- Гарантированные спавны: WaveTimelineConfig.Wave._guaranteed (offset, enemy, count) → SpawnWaveSystem.
- Иконки в проекте: GUI Pro-FantasyRPG (4487 png — рамки, панели, ленты), RGP icons free start pack (36),
  Blink/Art/Icons (50 иконок умений), GUI_Parts/Icons (11). VFX: Hovl Studio, Vefects, JMO.

======================================================================
2. ПЛАН ПО ФИЧАМ (порядок = порядок шагов)
======================================================================
Ф1. UI выбора перков — M
  - PerkConfig: + _icon (Sprite), + _rarity (enum Common/Rare/Epic/Legendary).
  - Карточка: иконка в рамке цвета редкости, пипсы уровня (следующий / макс), бейдж «КОМБО» с иконками
    родителей (_requires). Выбор как раньше (клик, клавиши 1–3).
  - Наведение: справа/слева от карточки выезжает панель (DOTween): имя, описание, модификаторы уровня
    «сейчас → после» (форматтер StatModifierEntry → «+20% скорость атаки»), для комбо — «требует: …».
  - Стиль: рамки/панели GUI Pro-FantasyRPG, иконки Blink/RGP — временные.
  - Новый префаб карточки, UpgradeChoiceView переписывается под N карточек (заготовка под 4 карточки Ф5).

Ф2. Цифры урона — M
  - Как разведка 060 §7: PlayDamageNumbersSystem (группа 12, Inc<DamageEvent, DamageApplied>) →
    IDamageNumberSink (Core) → пул world-space TMP во View: лимит 40 живых, слияние попаданий по одной цели
    в окне 0.12 с, на паузе замирают.
  - DamageNumberStyle: Normal белый, Crit красный, Magic синий, MagicCrit фиолетовый.
    В DamageEvent + IsCrit, + IsMagic. Источника крита/магии нет — стили видны только на стенде.
  - Настройки: тогл «Цифры урона» + слайдер размера (мин..макс). Тут же — GameSettings: JSON v1 в
    persistentDataPath (ответ В3), звук переезжает туда же.

Ф3. DPS — S
  - Левый нижний угол: средний DPS героя за скользящее окно (урон с Source = герой).
  - Клавиша ~ (backquote) — новое действие в GameControls, показ/скрытие, состояние в GameSettings.

Ф4. Элитные аффиксы — M
  - EliteAffixConfig (ContentConfig, стабильный ID): модификаторы статов, масштаб модели, VFX-префаб.
    Первые: «Крепкий» (HP ×2.5, масштаб ×1.2), «Быстрый» (скорость ×1.4, VFX у ног).
  - Случайная элитка: шанс на спавн обычного врага (в LevelConfig), отдельный поток случайности.
    Гарантированные спавны — всегда элитки со случайным аффиксом.
  - Через пайплайн: модификаторы с источником "elite.<affix>" при спавне (как разброс скорости 4A).
  - ГОЧА: сторож RecomputeStatsSystem кидает исключение при ускорении врага сверх таймлайна, а запас
    запросов индекса считается от MaxEnemyMoveSpeed / MaxEnemyBodyRadius. Множители аффиксов обязаны
    войти в EnemyMotionBounds (WaveTimelineValidator), иначе громкое исключение на первой быстрой элитке.
  - VFX по чеклисту ARCHITECTURE §13.1 (пул, NotBody), стресс-замер level.stress до/после.

Ф5. Предметы — L (самая большая; дробится внутри на 2–3 подшага с приёмкой)
  - ItemConfig (ContentConfig, ID): слот, имя, иконка, основной стат (StatId, op, значение на ранг 1..5).
  - Ролл: ранг 1..5, редкость Common/Rare/Epic/Legendary; редкость даёт 0/1/2/3 минорных бонуса из пула
    (AttackSpeed, MoveSpeed, PickupRadius, LifeOnKill...). Отдельный поток случайности от сида.
  - Убийство элитки → дроп → окно из 4 карточек (пауза, как перки), стиль Ф1 + сравнение с надетым
    в том же слоте (зелёный/красный).
  - Надевание: один предмет на слот, новый в слоте заменяет старый. Модификаторы — источник "item.<slot>".
  - Основные статы: скорость → MoveSpeed; урон → WeaponDamage; HP → MaxHealth; лайфстил → LifeOnHit;
    снижение урона → DamageTaken; «кд скиллов» — нужен новый стат (В5).

3. ВОПРОСЫ (решает разработчик)
======================================================================
В1. Предметы — внутри забега (сбрасываются в конце, сейвов не надо) или мета (GDD §8: сохраняются)?
    Рекомендация: внутри забега сейчас; мета-версия — с сейвами шага 9. GDD §8/§11 поправить.
В2. Слоты предметов. Рекомендация: оружие (урон), броня (HP / снижение урона), кольцо (лайфстил / урон),
    сапоги (скорость), амулет (кд). Артефакт не трогаем — это активная способность.
В3. «Грейд снятого запоминается» — для чего? Варианты: (а) показ в сравнении; (б) снятое можно вернуть
    позже; (в) задел под мету. Рекомендация: (а) сейчас.
В4. Редкость и ранг у ПЕРКА: у перков есть только уровень. Редкость — новое поле; влияет ли она на шанс
    выпадения или только на рамку? Что такое «ранг» перка — это уровень? Рекомендация: ранг = уровень,
    редкость пока только визуал.
В5. «КД скиллов»: только рывок (DashCooldown есть) или общий стат CooldownReduction на рывок + кулдауны
    перков (казнь, контрудар...)? Второе трогает каждую систему с кулдауном. Рекомендация: общий стат,
    но в Ф5 подключить к рывку и казни, остальные по мере надобности.
В6. Крит: только заготовка стиля (рекомендация) или сразу стат CritChance/CritDamage (тогда минорный
    бонус «+крит» у предметов и красные цифры в игре)?
В7. Дроп с элитки: сразу окно в момент убийства или лежащий сундук/предмет, к которому надо подойти?
    Рекомендация: лежащий предмет с подбором — окно не выскакивает посреди толпы.
В8. Тролль: остаётся элиткой «по типу» без аффикса, или тоже получает случайный аффикс?
В9. DPS — окно усреднения: последние 5 с (живая цифра) или с начала забега? Рекомендация: 5 с.
