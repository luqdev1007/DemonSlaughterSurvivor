Решения разработчика: Р8–Р12, П1, А1 (+А3′), б, в, г, з, и, к, л, н, о, р.

Однозначные решения агента:
  а) Окна ударов поставлены руками по замеру (LeftSlash тики 24–29,
     RightSlash 13–19, Spin 11–24 при скорости 2). Автоправило «первый…
     последний отсчёт» захватывало у RightSlash замах (тики 3.5–18.3); одного
     правила на три клипа нет. Инструмент предлагает окно, только если оно не
     задано.
  б) Прибавка к радиусу запроса взмаха — не константа, а фактические точки
     клинка этого тика; поэтому сдвиг героя за тик учитывается сам.
  в) Буфер попаданий — EcsPackedEntity[] в Swing с IEcsAutoReset: массив живёт
     вместе со слотом пула, сравнение по EqualsTo (id + поколение), так что
     новый враг с id погибшего не считается уже задетым.
  г) Трассировка сравнения тестов: WeaponSystemTests строят синтетический
     клинок и покрытие тем же SwingBaker.ComputeCoverage, что и настоящий.
  д) Сообщения исключений в EquipStartingWeaponSystem валидируют данные
     оружия громко: нет запекания, пустой сектор, скорость ≤ 0, пустое окно,
     полуугол вне (0, 90] и не ≥ 180.

Поток случайности (р). string.GetHashCode не годится — дословно из
документации .NET (String.GetHashCode, Remarks): «The hash code itself is not
guaranteed to be stable. Hash codes for identical strings can differ across
.NET implementations, across .NET versions, and across .NET platforms (such as
32-bit and 64-bit) for a single version of .NET… they should never be
persisted.» IL2CPP — другая реализация .NET. Взят FNV-1a 32 по UTF-8 байтам,
без аллокаций; значения заморожены тестом и совпали с независимым расчётом в
Python (weapon.berserk_sword = 3838912619).

А3′ — что поменяется при переключении (только StartSwingSystem):
  HasTarget: вместо config.TriggerCoverage — «любой вариант покрывает
    врага» (перебор config.Variant(i).Coverage);
  PickVariant: собрать индексы вариантов, покрывающих найденную цель, и
    выбрать один из них тем же одним вызовом NextUnit (число вызовов потока
    не меняется, меняется только диапазон). Покрытие каждого варианта уже
    лежит в данных — перезапекание не нужно.

Откат П1 → П2:
  1) в слое Attack заменить маску Berserk_Attack на Berserk_UpperBody;
  2) в SwingBaker.SampleClip после SampleAnimation клипа удара поставить
     Hips в позу из Idle (как в замере разведки);
  3) Game/Bake Weapon Swings, прогнать тесты.
  Цена: удары без поворота корпуса, Spin без вращения, ошибка клинка на
  бегу до 1.4 м (замер разведки).
